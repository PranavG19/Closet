Atelier — Baseline

The current Atelier design at its best — editorial restraint with warm cream canvas, sunken garment wells, serif display headings, hairline dividers, and a single earned crimson action per screen.

Signature move: Every garment is a clean CSS-drawn silhouette on a 6px sunken well, tinted per-piece via one custom property so the shapes read as white/black/camel/rose — no images, fully consistent.

Atelier — Warm

The existing Atelier system nudged one step cozier — a deeper cream canvas, warmer amber-toned shadows, ~15% more negative space, and slightly larger serif display moments.

Signature move: Re-tuned the shadow from neutral grey to a warm sepia so every card, well, and hero garment casts a soft honey-toned shadow — the whole surface reads as sunlit.

Atelier — Ivory Air

The quiet-luxury take: a cooler near-ivory canvas, thinner hairlines, quieter overlines, and a roomier grid that reads like gallery-white calm while keeping the lone crimson action and serif display.

Signature move: Dialed the whole system airier — cooler #FAF7F2 canvas, lighter hairlines, 10px overlines — so the single crimson action carries more weight against expanded negative space.

Atelier — Editorial Bold

The shipped Atelier system pushed to magazine-masthead scale — oversized serif display headings anchor each screen against generous cream space, with a single deliberate crimson action per view.

Signature move: A dramatic size jump between a 52–56px Georgia headline and 16px body, in confident left-weighted asymmetry, so each screen reads like an editorial cover rather than a settings list.

Atelier — Serif Throughout

The Atelier baseline rendered entirely in Georgia, retiring the sans so display, overlines, and body copy share one literary, bespoke-tailoring voice.

Signature move: Serif italics become the app's intimate voice (garment names, subtitles, 'signed in' values in Georgia italic), so typographic identity — not colour or layout — carries the variation.

Editorial Noir

The Atelier editorial system inverted into a warm-ink nighttime atelier — bone-cream type and the same serif display on deep charcoal, garment cutouts floating on darker wells lit by a soft spot, with the crimson action now glowing.

Signature move: The crimson accent literally emits light — every earned action carries a soft crimson glow, so the one accent reads as the only warm light source in a dark room.

Lookbook (imagery-forward)

A magazine-lookbook reframe that keeps cream/serif/single-crimson but pushes garments edge-to-edge in a tight two-column spread, overlays type on imagery, and turns Today into a full-screen cover.

Signature move: Edge-to-edge full-bleed garment tiles with the name/state caption and a magazine '01–04' number tag set over each image on a soft gradient — dropping card chrome so the closet reads as a printed spread.

Studio Pop

A joyful Gen-Z boutique departure that trades cream-and-crimson restraint for confident colour-blocked panels (electric grape, hot tangerine, zesty lime), oversized italic display type, and rounder shapes — loud in palette but still minimalist in composition.

Signature move: Each tile sits on its own full-saturation candy-tinted well and the Today reveal becomes a radial tangerine-to-magenta hero with floating blend-mode blobs — colour-blocking promoted from accent to structural surface.

20% · a step away

Atelier — Linen & Sage

A one-step palette shift of the Atelier system that keeps every structural bone — serif display, hairline dividers, sunken wells, one earned action per screen — but re-voices the single accent from crimson to a muted botanical sage-green over a linen-warmed canvas, with availability dots re-tuned (leaf/wheat/stone) to sit calmly beside the new accent.

Signature move: Retiring crimson entirely for sage as the sole "earned action" color while quarantining destructive Delete onto a separate earthy-clay red — so sage never has to double as both invitation and warning, keeping the one-action-per-screen discipline intact.

20% · a step away

Atelier — Tactile Cards

A one-step depth shift on the Atelier system: the same cream, Georgia serif and single crimson action, but garments and account sections now lift off the surface as soft-shadowed paper cards with slightly larger radii, giving physical, tactile materiality without becoming heavy.

Signature move: Layered warm elevation replaces hairline dividers everywhere — garment tiles become raised white cards over a recessed well, and the Today hero garment sits on a raised circular pedestal like an object on a plinth.
